# Промо-ролик Оспорим

| Файл | Формат | Звук |
|---|---|---|
| `ospori-promo-16x9-music.mp4` | 1920×1080, 25 с, 30 fps | музыка, −15 LUFS |
| `ospori-promo-9x16-music.mp4` | 1080×1920, 25 с, 30 fps | музыка, −15 LUFS |
| `ospori-promo-9x16.mp4` | 1080×1920, 25 с, 30 fps | без звука |

- `promo.html` — исходник анимации. В браузере проигрывается по кругу, клик ставит на паузу. `?ar=16x9` — горизонтальная раскладка.
- `render.js` — покадровый рендер в MP4 (Playwright + ffmpeg):
  `FFMPEG=/path/to/ffmpeg node render.js out.mp4 30`, для 16:9 — с `AR=16x9`.
- `music.py` — оригинальный трек, синтезируется кодом (numpy + scipy), права не нужны. 112,5 BPM, смены сцен попадают в доли: напряжение на зацепке, грув с «Не спешите платить», акцент на цене, разрешение в мажор на логотипе.
  `python3 music.py music.wav`, затем сведение:
  `ffmpeg -i video.mp4 -i music.wav -map 0:v -map 1:a -c:v copy -af loudnorm=I=-16:TP=-1.5 -c:a aac -b:a 192k -shortest out.mp4`

Перед запуском рекламы заменить плейсхолдеры в финальной плашке: `[Юрлицо]`, `[ИНН]`, `erid: [токен]`.
