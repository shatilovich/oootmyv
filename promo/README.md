# Промо-ролик Оспорим

`ospori-promo-9x16.mp4` — 1080×1920, 25 с, 30 fps, без звука (Reels / Shorts / VK Клипы).

- `promo.html` — исходник анимации. Открыть в браузере — проигрывается по кругу, клик ставит на паузу.
- `render.js` — покадровый рендер в MP4 (Playwright + ffmpeg):
  `FFMPEG=/path/to/ffmpeg node render.js ospori-promo-9x16.mp4 30`

Перед запуском рекламы заменить плейсхолдеры в финальной плашке: `[Юрлицо]`, `[ИНН]`, `erid: [токен]`.
